# Phoenix Admin Host 业务插件界面

## 页面

本地地址：<http://localhost:9000/pah/plugins>。

页面独立于上游 Cool `.cool` 插件商店，用于登记 Phoenix 跨前后端业务插件的
manifest，并展示已登记插件的生命周期、导航模块、数据所有权与 Host 复用声明。
Host 仓库不内置任何产品候选 manifest；管理员应从独立业务插件包取得 JSON 清单并
粘贴登记。

## 可验证流程

```text
登记清单 → 已验证 → 安装 → 已安装 → 启用 → 已启用
                                    ↓
                                 停用 → 卸载（保留数据）
```

卸载对话框明确提示只注销代码、路由和任务贡献；成功后页面展示保留表数量和备份标识。
所有操作都以清单自己的 `moduleId` 为目标，不依赖任何特定产品名称、路由或表前缀。

## Host 边界

- 页面只把 JSON 声明发送给 Node Host 校验，不上传包、不读取入口文件、不执行源码。
- 首版只接受 `restart` 激活方式；实际入口加载必须进入受控构建或重启流程。
- Web/Node 入口、路由、API、能力码和迁移 ID 必须留在插件自己的命名空间。
- 卸载固定保留业务数据并要求可恢复的备份标识。
- 已安装清单只驱动通用生命周期与导航贡献，不成为产品配置的第二事实源。
