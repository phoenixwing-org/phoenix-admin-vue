# Phoenix Admin Vue 0.2.0

## 发布基线

- 分支：`develop`
- 前端宿主：Phoenix Admin Vue `0.2.0`
- 工作台依赖：Registry `phoenix-wing@0.6.2`
- 上游兼容基线：Cool Admin Vue `8.x` / `a2d4ee9bbfd6bfce880382f0bf6f8dd8f3397a2d`

## 主要变化

- 完善 Phoenix Wing 工作台宿主：统一导航、主题、Primary/Bottom、隐藏深链与插件 View 承载。
- Bottom 使用全局自由文本输出流，切换 View 时保持实例内消息；结构化诊断与审计日志仍由各业务能力负责。
- 增加字典治理与幂等补全界面，支持插件稳定命名空间和受控字典贡献。
- 将业务插件入口统一为 `/phoenix/plugins`，提供 `.phoenix.cool` 制品校验、受控重启检查、迁移 dry-run、可信备份、安装、启停和保留数据卸载的顺序向导。
- 锁定公开 Registry `phoenix-wing@0.6.2`，不依赖本地源码 resolver 作为正式运行依赖。

## 发布边界

- Phoenix 业务插件源码和产品映射不进入 Host 仓库。
- 尚未完成生产环境联调的独立候选功能不进入本次发布。
- 插件运行时热加载尚未承诺；当前仍使用受控构建与重启激活。

## 升级检查

```shell
pnpm install --frozen-lockfile
pnpm test
pnpm type-check
pnpm build
```

前后端必须使用各自的 0.2.0 发布提交。标签与 `master` 合并由发布负责人在两端门禁完成后统一执行。
