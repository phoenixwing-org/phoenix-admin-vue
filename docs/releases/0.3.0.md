# Phoenix Admin Vue 0.3.0

## 发布定位

`0.3.0` 汇总 Phoenix Admin 前端近期的 Host 能力升级：统一 Phoenix 插件生命周期、
开发挂载就绪检查、工作台品牌配置、导航分组、系统维护、Host Files 与 Wing View 呈现。

## 主要能力

- 开发挂载与插件中心生命周期分层展示，源码挂载优先且不会被安装包覆盖；
- 支持保留并恢复已验证插件包，安装、升级、停用和卸载状态可追踪；
- 工作台品牌配置与品牌插件切换使用同一安全快照契约；
- Phoenix 插件 View 默认接入 Wing 的嵌入、浮出与收回能力；
- 提供 Host Files 前端适配器、导航分组、字典维护和系统维护入口；
- Registry 依赖精确锁定 `phoenix-wing@0.7.2`。

## 发布边界

- 不包含任何业务插件产品源码；
- 不使用 `file:`、`link:`、`workspace:` 或 override 代替 Registry 制品；
- 本地归档不创建 tag、不 push，由发布负责人完成远端发布。
