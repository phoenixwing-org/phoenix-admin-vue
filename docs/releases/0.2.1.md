# Phoenix Admin Vue 0.2.1

## 版本性质

`0.2.1` 是 `0.2.0` 的向后兼容补丁版本，不改变插件 manifest、生命周期、路由或业务 API 契约。

## 修复与诊断

- 修复 Pah 外部插件依赖解析的 Windows 路径兼容问题，统一反斜杠、Vite 正斜杠、file URL 与查询参数。
- 使用逻辑路径与 realpath 双重判断 Host 边界，正确识别普通外部目录、带空格目录及挂载在 `src/modules` 下的 Junction 插件。
- Host 自身通过 Junction 打开时仍按物理根目录识别自有源码。
- 新增 `pnpm diagnose:cool-eps`，脱敏显示 EPS 后端连通性、本地缓存状态和启动影响分类。
- 说明标准 `pnpm dev` 中 cool-eps 远端不可达日志的降级语义，避免把非阻断日志误判为 Vite 启动失败。
