# Phoenix Admin Vue 0.2.2

## 版本性质

`0.2.2` 是 `0.2.1` 的向后兼容补丁版本，收口 Phoenix 业务插件的统一入口、简化安装向导、
候选制品清理和安装状态呈现。插件 manifest、迁移格式和业务 API 契约保持兼容。

## 插件管理

- Phoenix 插件统一使用 `/phoenix/plugins`；`/helper/plugins` 的 Primary 在 Cool 插件与
  Phoenix 业务插件之间切换，不再保留 `/pah/plugins` 兼容入口；
- 卡片展示 Phoenix SVG、版本、发布者/日期、导航模块、迁移、业务表和能力标签；
- 安装阶段收敛为选择/验证、运行点检、安装并启用，停用和保留数据卸载保持独立操作；
- 已验证但尚未安装的候选可“移除已选包”，明确不执行 SQL、不删除业务数据、迁移台账
  或管理员分组；
- 注销或卸载后清理失效页签和导航入口，避免保留已不存在的业务 View；
- 新 Node payload 未进入运行进程时，按钮旁显示确定的“需要重启 API”阻断原因。

## 运行与扩展边界

- 浏览器不执行插件提供的命令，Host 不按插件输入临时运行 `pnpm install`；
- 当前仍采用受控构建与重启，不宣称 Midway/Vite 进程内热插拔；
- payload 安全激活、外部 supervisor 重启、回滚和热插拔研究见
  [PahPLUGIN-RUNTIME-TODO.md](../PahPLUGIN-RUNTIME-TODO.md)；
- 可插拔登录外观、权限内首页和品牌资源接缝见
  [PahUIEXTENSION-TODO.md](../PahUIEXTENSION-TODO.md)。

## Wing 依赖

本版本精确锁定 Registry `phoenix-wing@0.6.3`，lockfile 记录公开 tarball 的完整性摘要。
不使用 `file:`、`link:`、`workspace:`、override 或本地 `node_modules` 代替正式依赖。

## 发布门禁

- Phoenix 插件管理定向测试、Pah 测试、Vue 类型检查和 production build；
- Registry lockfile 不包含本地依赖协议，运行时 `PNW_VERSION` 必须为 `0.6.3`；
- 不包含任何业务插件产品源码或产品映射；
- 不创建 tag、不推送，由发布负责人完成稳定分支合并和正式发布。
